Why decibri-cli

An audio CLI that works everywhere your scripts do.

decibri-cli is a focused audio I/O tool for scripts and CI: one statically-linked binary with no runtime dependencies to install on Windows and macOS, installed in seconds via Homebrew, Scoop, npm, cargo, or a direct download.

No system tools required.

No SoX, no ffmpeg, no arecord. Install and run. Nothing else to configure.

Works where you already work.

Windows 11, macOS (Intel + Apple Silicon), and Linux (x64 + arm64) from the same commands.

Built to be scripted.

Machine-readable --json output and stable exit codes for CI, pipelines, and automated diagnostics.

Core Features

Four commands. One binary.

Everything decibri-cli does. A tool built for capture, playback, and device enumeration.

decibri capture

Record 16-bit PCM WAV from any input device. ASR-ready defaults (16 kHz mono). Ctrl+C produces a valid truncated file, never corruption.

decibri play

Play 16-bit PCM or 32-bit float WAV through any output device. Clean Ctrl+C stop, stable exit codes.

decibri devices

Enumerate inputs and outputs with sample rates and channel counts. Select by name substring or numeric index.

decibri version

Report version, audio backend (WASAPI / CoreAudio / ALSA), target triple, and Rust version. Stable JSON schema.

Install

Pick whichever fits your workflow.

Homebrew (macOS and Linux):

$ brew tap decibri/decibri Copied!
$ brew install decibri-cli Copied!

Covers macOS and Linux, on both Intel and arm64. Downloads the pre-built release archive and installs the decibri binary, so nothing is compiled. On Linux, Decibri needs the ALSA runtime library libasound.so.2, which Homebrew does not provide: install it with sudo apt install libasound2 on Debian/Ubuntu, sudo dnf install alsa-lib on Fedora, or sudo pacman -S alsa-lib on Arch. That is the runtime library, a different package from the libasound2-dev development headers needed to build from source with cargo.

Scoop (Windows):

$ irm get.scoop.sh | iex Copied!
$ scoop bucket add decibri https://github.com/decibri/scoop-decibri Copied!
$ scoop install decibri-cli Copied!

Windows, 64-bit only. The first command installs Scoop itself, once, in PowerShell, and needs no administrator rights. The next two add the Decibri bucket and install the CLI.

npm (any platform):

$ npm install -g decibri-cli Copied!

Downloads the platform binary, verifies the SHA256, adds it to your PATH. No Node.js runtime required after installation.

cargo (from source):

$ cargo install decibri-cli Copied!

Builds from source. Requires Rust stable. Linux needs libasound2-dev.

How it fits

Built on the Decibri library.

decibri-cli is a thin shell over the decibri Rust crate, which is the same library that powers the decibri Node.js package. If you've used decibri from Node, the CLI uses the exact same audio backend (cpal) underneath; the browser runtime shares the same API through a JavaScript implementation. Capture a WAV on the command line, then load it in a Node script with decibri. Same audio format, same device semantics, same cross-platform coverage.
